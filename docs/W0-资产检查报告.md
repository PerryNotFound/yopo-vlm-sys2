## 2. A3 静态地形假设验证（≤ 6 s 窗口内危险区不移动、不扩张）

逐条核实：

1. **水坑 prefab（WaterTemp）**：仅含 MeshFilter + MeshRenderer，无 Animator/Animation/任何脚本组件 → 放置后不可能移动。
2. **VLMWater 材质**：纯色无贴图（_BaseMap 为空）→ 不存在 UV 滚动动画。
3. **PuddleRandomizer.cs**：只在 Start/地形重随机时放置一次，无 Update 中位移逻辑（grep `_Time|scroll` 无命中）。
4. 原 WaterDepthBased 透明水材质已弃用（M5 起），不参与闭环。

结论：在 SRA 有效期窗口（≤ Δ_phys + Δ_vlm_95，实测 ≤ 6 s）内危险区静止，**A3 可测且成立**。动态危险（涨水等）按 handoff 约定写入论文 limitation。

## 4. 怎么看 W0 的实验结果（人工目检步骤）

W0 的"实验结果"是**视觉混淆度**，需要人眼/VLM 判断，步骤：

1. 打开 Unity 工程 `YOPO-Sim-Project`，等右下角编译/导入完成（新资产会自动识别）。
2. 打开 `Assets/Scenes/EvaluationScene.unity`。
3. 从 `Assets/Prefabs/` 把 **WetAsphaltTemp** 和 **ShadowBlobTemp** 各拖一个到场景里（Hierarchy 空白处右键 → 3D Object 旁边拖入即可），Inspector 里把 Position 改到水坑附近（参考水坑坐标：Console 里 PuddleRandomizer 打印的位置，或先拖进去再拖到地形上）。
4. 在 Scene 视图里对比三样东西：**水坑（亮蓝）/ 湿沥青（深灰反光）/ 软阴影（黑斑块）**。
5. 判断标准（门禁口径）：
   - 站在车相机视角（选 Hierarchy 里 DiabloWithSensors → RGBCamera_ros，看右下角预览小窗）；
   - 如果**湿沥青和水面一眼就能区分**（颜色差太多），把 `WetAsphalt.mat` 的 BaseColor 往蓝调一点（改 `_BaseColor` 的 b 分量 0.105 → 0.2 左右）、光滑度保持 ≥0.7；
   - 软阴影如果觉得太假，调 `SoftShadow.mat` 的 `_BaseColor` 的 alpha（0.55 → 0.3~0.7）。
6. 截图发我（Scene 视图或 Game 视图都行），我来做 VLM 视角的二次确认。

> 注意：新材质只影响显示效果，不进语义 GT（GT 仍由四分类语义相机产出）；S3 建场景时湿沥青/阴影区域在 GT 里标为"安全"，这正是"视觉混淆"的意义——看起来像危险，实际安全。
